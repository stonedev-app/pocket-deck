# 使い方

## SDカードの準備

SDカードのルート直下に、WAVファイルを置く。

| 項目 | 条件 |
|------|------|
| ファイルシステム | FAT（起動時にマウントし、失敗してもフォーマットはしない） |
| 置く場所 | ルート直下。サブディレクトリの中は探さない |
| 拡張子 | `.wav`（大文字小文字は区別しない） |
| 形式 | PCM（フォーマットタグ1）、16bit、モノラルまたはステレオ |
| サンプルレート | 指定なし（WAVに書かれた値のまま再生する） |
| チャンクの順 | `fmt`チャンクが`data`チャンクより前にあること。`LIST`などは読み飛ばす |
| ファイル名 | 日本語（UTF-8）も表示できる |

- `.`で始まる名前のファイル（macOSが作る`._`の隠しファイルなど）は一覧に出ない。
- 一覧は、大文字小文字を区別しない昇順で並ぶ。同じなら、バイト順。日本語はUTF-8のバイト順で、五十音順にはならない。
- 曲の一覧は起動時に1回だけ読む。曲を足したり消したりしたら、再起動する。
- 一覧には出ても、上の形式でないWAV（24bit、浮動小数点、圧縮形式など）は、選んでも再生が始まらない。
- SDカードがマウントできないときは、画面に`Init failed:`と理由を出して止まる。

## キー操作

押した瞬間に1回だけ動く（押しっぱなしでは繰り返さない）。矢印とEscはキーボードに専用のキーがなく、Fnとの組み合わせで入れる。

| 操作 | キー | Fnとの組み合わせ | 働く場所 |
|------|------|-------------------|----------|
| 次の項目へ | `j` | Fn + `.`（↓） | 一覧 |
| 前の項目へ | `k` | Fn + `;`（↑） | 一覧 |
| 決定（再生を始める） | Enter | | 一覧 |
| 戻る（再生を止めて一覧へ） | | Fn + `` ` ``（Esc） | 再生中の画面 |
| 一時停止 / 再開 | Space | | 再生中の画面 |
| 次の曲 | `l` | Fn + `/`（→） | 再生中の画面 |
| 前の曲 | `h` | Fn + `,`（←） | 再生中の画面 |
| 1曲リピートの入 / 切 | `r` | | 再生中の画面 |
| 音量を上げる | | Fn + `A` | どの画面でも |
| 音量を下げる | | Fn + `S` | どの画面でも |
| 消音 / 解除 | | Fn + `D` | どの画面でも |

- `j` / `k` / `l` / `h` / `r`は、Shiftを押さずに小文字で入れる。
- 一時停止中は、再生位置を覚えている。`Stopped`（曲が終わった後）にSpaceを押すと、今の曲を最初から再生する。
- 次の曲は一覧の最後、前の曲は先頭では何もしない。曲が終わっても、自動では次の曲に進まない。
- 1曲リピートがオンのときは、曲が最後まで再生されると、同じ曲を最初から始める。オフにするまで続く。
- 音量は0〜16の17段階。変えた段階は保存され、次の起動で戻る。消音は保存せず、起動時は必ず解除される。消音中に音量を上げ下げすると、消音が解除される。

## 画面の見方

画面は240 × 135で、上に帯、その下に一覧か再生中の画面が出る。

### 帯（上端）

右寄せで、左から音量、電池が並ぶ。

- 音量: 数字（0〜16）と、スピーカーのアイコン。段階に応じて、弧が0〜3本になる。消音のときは、暗いスピーカーに赤い斜線が入り、数字も暗くなる。
- 電池: 残量を示す。残量が少ないときは赤になる。充電中の表示はしない。

### 一覧

SDカードのWAVが、1行1曲で並ぶ。選んでいる行は、青い地に白の文字で出る。一度に約6行が見える。曲が1つもないときは「(none)」と出る。

### 再生中の画面

上から順に出る。

| 場所 | 内容 |
|------|------|
| 曲名 | 長いときは、流れて見せる |
| バー | 再生位置（青）。長さに対する割合 |
| 状態 | 左に「再生中」「一時停止」「停止」のいずれか |
| リピート | 中央に、リピートがオンの間だけ「リピート」（緑） |
| 時間 | 右に`mm:ss / mm:ss`（再生位置 / 長さ） |
| イコライザー | 緑の棒12本。低い音が左、高い音が右。一時停止・停止中は0に戻る |

再生位置は、スピーカーに渡した量で数えるので、実際の音より最大で約0.1秒進む。
