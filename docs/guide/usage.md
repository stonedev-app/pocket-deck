# 使い方

## SDカードの準備

SDカードのルート直下に、WAVファイルを置く。

| 項目 | 条件 |
|------|------|
| ファイルシステム | FAT |
| 置く場所 | ルート直下 |
| 形式 | WAV（16bit） |

## キー操作

矢印とEscは専用のキーがないので、Fnと組み合わせて入力する。

| 操作 | キー | Fnとの組み合わせ | 使える画面 |
|------|------|-------------------|------------|
| 次の項目へ | `j` | Fn + `.`（↓） | 一覧 |
| 前の項目へ | `k` | Fn + `;`（↑） | 一覧 |
| 決定（再生を始める） | Enter | | 一覧 |
| 戻る（再生を止めて一覧へ） | | Fn + `` ` ``（Esc） | 再生中の画面 |
| 一時停止 / 再開 | Space | | 再生中の画面 |
| 次の曲 | `l` | Fn + `/`（→） | 再生中の画面 |
| 前の曲 | `h` | Fn + `,`（←） | 再生中の画面 |
| 1曲リピートのオン / オフ | `r` | | 再生中の画面 |
| 音量を上げる | | Fn + `A` | すべて |
| 音量を下げる | | Fn + `S` | すべて |
| 消音 / 解除 | | Fn + `D` | すべて |

### 画面の自動消灯

電池を長持ちさせるため、キー操作がないとバックライトを落とす。
画面の描画と再生は、そのまま続く。

- 30秒操作がないと、バックライトが暗くなる。
- さらに30秒操作がないと、バックライトが消える。
- 暗い・消えている間にキーを押すと、元の明るさに戻る。
  そのキーは戻すためだけに使い、操作としては無視する
  （音量のキーでも音量は変わらない）。

## 画面構成

上にステータスバー、その下に一覧か再生中の画面が出る。

### ステータスバー

| 表示 | 内容 |
|------|------|
| 音量 | 数字とスピーカーのアイコン。消音中は赤い斜線が入る |
| 電池 | 残量。少なくなると赤くなる |

### 一覧

曲が1行ずつ並ぶ。選んでいる行は青く表示される。

### 再生中の画面

| 表示 | 内容 |
|------|------|
| 曲名 | 長いときは流れる |
| バー | 再生位置 |
| 状態 | 再生中・一時停止・停止 |
| リピート | オンの間だけ出る |
| 時間 | 再生位置 / 曲の長さ |
| スペクトル表示 | 音の高さごとの強さ。左が低い音 |
