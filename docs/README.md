# ドキュメント

pocket-deck の文書の目次。内容ごとに、次の 3 つの区分に分ける。

- `architecture/`: ソースの構成、タスクやモジュールの役割分担など、アプリの内部設計を書く。
- `hardware/`: Cardputer-Adv のハードウェアと、その周辺機器の使い方を書く。
- `guide/`: SD カードの準備やキー操作など、使い方を書く。
