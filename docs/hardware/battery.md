# 電池

## 仕様と接続

残量は、M5Unifiedを通して読む。  
ピンやアドレスの設定は、M5Unifiedが行う。

## 使い方

ステータスバーの電池の表示が、一定間隔で残量を読む。  
残量が15%以下になると、赤く表示する。  
残量が取れないときは、中身を空にして表示する。

## 注意点

| 内容 | このプロジェクトでの対応 |
|------|--------------------------|
| 充電中かどうかは取れない（実機で確認） | 充電中の表示はしない |
| 読むたびに値が少しぶれる | 前回から3%以上変わったときだけ、表示を更新する。0%と100%は、すぐに反映する |
