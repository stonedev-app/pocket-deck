# キーボード

## 仕様と接続

キーマトリクスコントローラTCA8418を、内部I2Cでつないでいる。I2Cアドレスは0x34。  
基板の4行 × 14列のキーを、TCA8418の7行 × 8列に折り畳んで接続している。  
M5Unifiedにはキーボードの機能がないので、レジスタを直接読み書きする。

| 信号 | ピン |
|------|------|
| SCL | GPIO9 |
| SDA | GPIO8 |
| INT | GPIO11（Lowで通知） |

### 使うレジスタ

| 名前 | アドレス | 内容 |
|---|---|---|
| `CFG` | 0x01 | bit0（`KE_IEN`）でキーイベントの割り込みを有効にする |
| `INT_STAT` | 0x02 | bit0（`K_INT`）がキーイベントの割り込みフラグ。1を書くと消える |
| `KEY_LCK_EC` | 0x03 | 下位4ビットがイベントの件数 |
| `KEY_EVENT_A` | 0x04 | イベントのFIFO。1回読むごとに1件取り出す |
| `KP_GPIO1` | 0x1D | bit0〜7がROW0〜7。1でキーマトリクス、0でGPIO |
| `KP_GPIO2` | 0x1E | bit0〜7がCOL0〜7。同上 |
| `KP_GPIO3` | 0x1F | bit0〜1がCOL8〜9。同上 |

### イベントの1バイト

- bit7が1なら押下、0なら離上。
- 下位7ビットが、1始まりのキー番号。0はイベントがないことを示す。
- キー番号から1を引いた値をvとすると、行はv / 10、列はv % 10（1行に10個）。

### 物理配列への変換

TCA8418の`(rawRow, rawCol)`を、4行 × 14列の物理配列の`(row, col)`に直す。

```cpp
col = rawRow * 2 + (rawCol > 3 ? 1 : 0);
row = (rawCol + 4) % 4;
```

## 使い方

キーは、押した瞬間だけ通知する。離したときや、押しっぱなしの繰り返しは通知しない。  
割り込みはタスクを起こすだけで、I2Cの読み書きはタスクで行う。  
割り込みを取りこぼしても止まらないよう、一定間隔でも読みにいく。

### Fn層

Fnを押している間は、次のキーが別の意味になる。Fn層に定義がないキーは、通常のキーとして扱う。

| Fn + | 意味 |
|------|------|
| `;` `,` `.` `/` | ↑ ← ↓ → |
| `` ` `` | Esc |
| `del` | Delete（Fnなしは Backspace） |
| 英字 | Fn付きの英字として通知する（Fn + A / S / Dで音量を操作する） |

## 注意点

| 内容 | このプロジェクトでの対応 |
|------|--------------------------|
| INTがLowのまま残ると、次の割り込みが来ない | 初期化で、溜まったイベントと割り込みフラグを消す |
| 割り込みの処理は、タスクを起こすためにタスクの情報を使う | 割り込みの登録は、タスクを作った後に行う |
| 公式サンプルの`keymap.h`は、GPLv3の著作権表記を含む | 使わずに、キー配列を自前で定義している |
