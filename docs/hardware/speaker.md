# スピーカー

## 仕様と接続

- コーデックES8311を、I2Sでつないでいる。
- コーデックとI2Sの設定は、M5Unifiedが行う。
- 音は`M5.Speaker`で出す。

## 再生の仕組み

音声ファイルはメモリに収まらないので、少しずつ読んで`M5.Speaker`に渡す。  
バッファは3個を順番に使う。  
音切れが出るときは、バッファを大きくするか、数を増やす。

## 音量

- 0〜16の17段階。小さい音量ほど細かく刻んでいる。
- 最後の変更から1秒後に保存する。消音は保存しない。

## 注意点

| 内容 | このプロジェクトでの対応 |
|------|--------------------------|
| `playRaw()`に渡したバッファは、鳴り終わるまで使われ続ける | バッファを3個回し、鳴っている間は書き換えない |
| `playRaw()`の長さは、バイト数ではなく要素数 | 要素数で渡す |
| 受け取る側がいっぱいだと、`playRaw()`は空くまで待つ | 再生は専用のタスクで行う |
| 起動済みのとき、`begin()`は何もしない | 設定の前に、一度`end()`で止める |
| `setVolume()`は、`begin()`の後でないと反映されない | 音量の復元は、起動の後に行う |
