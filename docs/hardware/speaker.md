# スピーカー

## 部品とつなぎ方

- コーデック ES8311 を I2S でつないでいる。
- コーデックの有効化（I2C でのレジスタ書き込み）と I2S のピン設定は、M5Unified が行う。このプロジェクトのソースには、スピーカーのピン番号を書いていない。
- 音は `M5.Speaker`（`m5::Speaker_Class`）で出す。

## このプロジェクトでの使い方

関連するソースは次のとおり。

| ファイル | 役割 |
|---|---|
| `main/audio/speaker.cpp` | `speaker::begin()`。スピーカーのタスクの設定と起動、音量の復元 |
| `main/audio/volume.cpp` | 音量の段階の管理と保存 |
| `main/audio/player.cpp` | WAV を `M5.Speaker.playRaw()` で再生する |
| `main/audio/wav.cpp` | WAV のヘッダの解析 |

### 初期化

`speaker::begin()` を、`M5.begin()` の後に、起動時に 1 回だけ呼ぶ（`main/startup.cpp`）。

1. `M5.Speaker.end()` で止める（`begin()` は開始済みだと何もしないため）。
2. タスクの優先度とコアを、`main/task_config.hpp` の `SPEAKER` に設定する。
3. `M5.Speaker.begin()` で起動する。
4. `volume::begin()` で音量を復元する。

### 再生（チャンク再生）

SD カード上の WAV は、メモリに収まらないので、小さなバッファに分けて `playRaw` で順に渡す（`main/audio/player.cpp`）。

- `player::start()` が再生専用のタスクを作る。タスクは `wav::parse()` が返した `data` チャンクの範囲だけを読む。
- バッファは `int16_t` の 2048 要素を 3 個、順番に使う。読んだ要素数を `playRaw(buf[i], n, sampleRate, stereo, 1, CHANNEL)` に渡す。チャンネルは 0 を明示する。ステレオのときは、1 回に読む要素数を偶数にそろえる。
- 最後まで読んだら、`M5.Speaker.isPlaying(0)` が偽になるまで待って終える。終了の理由（`Finished` / `Stopped` / `Failed`）を、キュー（長さ 4）で知らせる。受け取るのは `main/app/playback.cpp`（`player::receive()`）。
- `player::stop()` は停止の要求を立て、`M5.Speaker.stop(0)` でキューを空にし、タスクの終了を待つ（上限 2 秒）。
- 対応する WAV は、16bit PCM のモノラル / ステレオのみ（`wav::parse()` が、それ以外の形式の理由を返す）。

### 音量

`volume::up()` / `down()` / `toggleMute()` で操作する。

- 段階は 0〜16 の 17 段階。`setVolume` に渡す値は、`volume.cpp` の `VOLUME_TABLE` から引く（0 段目は 0、1〜16 段目は 6, 8, 10, 13, 16, 21, 27, 35, 44, 57, 73, 94, 120, 154, 198, 255）。下の側を細かくしてある。
- 消音中は 0 を渡し、段階は覚えておく。消音は保存せず、起動時は必ず解除する。
- 段階は NVS（名前空間 `pocket-deck`、キー `vol`、1 バイト）に保存する。最後の変更の 1 秒後に 1 回だけ書く（連打でフラッシュの書き込み回数を消費しないため）。保存がなければ 4 段目になる。
- NVS が使えなくても、既定値で動かす。

## 注意点

- `playRaw` は、渡したバッファを再生が終わるまで参照し続ける。キューにはポインタしか積まないので、再生が終わるまで、そのバッファを書き換えたり解放したりしない。バッファを 3 個回すのは、このため。
- `playRaw` の `array_len` は、バイト数ではなく、要素数。
- チャンネルを明示した `playRaw` は、キューに空きがないとき、空きが出るまで待つ。再生ループはこれに頼っているので、キー入力と描画を行うタスクとは別のタスクで再生する。
- 音の経路のタスク（スピーカー・再生用）は、描画のタスクより優先度を高くし、コア 0 に置く。優先度が低いと、描画が忙しいときに音が途切れる（実機で確認）。値の理由は `main/task_config.hpp` に書いてある。
- `M5.Speaker.setVolume()` は、`M5.Speaker.begin()` の後でないと反映されない。
- 音切れが出たときは、バッファの要素数を大きくするか、個数を増やして調整する。
