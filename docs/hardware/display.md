# ディスプレイ

## 仕様と接続

240×135ピクセルの横長の液晶。画素の形式はRGB565（16bit）。  
SPIで接続されている（SDカードとは別のSPI）。

| 信号 | ピン |
|------|------|
| SCLK | GPIO36 |
| MOSI | GPIO35 |
| DC | GPIO34 |
| CS | GPIO37 |
| RST | GPIO33 |
| バックライト | GPIO38 |

ピンの設定は、M5GFXがボードを判定して行う。

## 使い方

描画はLVGLが行い、描いた領域を画面に転送する。  
LVGLの描画バッファは、画面全体ではなく40行ぶん。  
初期化に失敗したときは、LVGLを使わず、画面に直接エラーを出す。

## 注意点

| 内容 | このプロジェクトでの対応 |
|------|--------------------------|
| 画面の大きさは、`M5.begin()`の後でないと正しく取れない | `M5.begin()`の後に読む |
| LVGLには、転送が終わったことを知らせる必要がある | 転送が終わるまで待ってから知らせる |
