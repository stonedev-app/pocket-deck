# SDカード

## 仕様と接続

SDカードは、SPIで接続されている（SDMMCではない）。

| 信号 | ピン |
|------|------|
| SCLK | GPIO40 |
| MOSI | GPIO14 |
| MISO | GPIO39 |
| CS | GPIO12 |

M5UnifiedにはSDカードの機能がないので、ESP-IDFのSDカード用の機能（SPI接続とFAT）を直接使う。

## 使い方

起動時に、SDカードを`/sdcard`にマウントする。  
その後は、通常のファイル操作で読める。  
長いファイル名と日本語のファイル名を読めるように、`sdkconfig.defaults`で設定している。

## 注意点

| 内容 | このプロジェクトでの対応 |
|------|--------------------------|
| マウントに失敗したとき、SPIを解放しないと、次の初期化が失敗する | 失敗したら解放する |
| 自動フォーマットを有効にすると、マウントに失敗したカードの中身が消える | 無効にしている |
| 読み出しはCPUを使い続ける | 音声ファイルの読み込みは、描画と別のコアで行う（[tasks.md](../architecture/tasks.md)を参照） |
